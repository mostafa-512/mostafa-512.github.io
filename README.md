## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn/pnpm

### Installation & Development

1. **Clone the repository:**
```bash
git clone https://github.com/mostafa-512/mostafa-512.github.io.git
cd mostafa-512.github.io
```

2. **Install dependencies:**
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. **Run the development server:**
```bash
npm run dev
```

4. **Open your browser:**
Navigate to [http://localhost:3000](http://localhost:3000) to see the portfolio in action.

The page auto-updates as you edit files in `src/app/`.
